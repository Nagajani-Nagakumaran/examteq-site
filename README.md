

Educational web platform developed for 11+ preparation, with interactive learning resources and online practice materials.

## ✨ Features

- Interactive topic-based practice
- Online learning resources
- Practice tests and revision materials
- Student-friendly navigation and responsive layout

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 💻 My Contribution

I designed and developed the platform, including the site structure,
user interface and interactive learning functionality.

The project was built to support digital delivery of ExamTeq's
educational resources and provide students with an accessible way
to practise outside lessons.
